Privacy & local storage

Patient information stays on this device.

DoctorJet RX does not send patient names, phone numbers, diagnoses, prescriptions or consultation notes to the DoctorJet server. Data is stored in this browser profile using IndexedDB. Anyone with access to this Mac and browser profile may be able to access the records. Use a separate macOS account, a strong Mac login password and FileVault. Do not use a shared/public computer.

This is browser-local storage, not a Finder-visible SQLite database. It does not synchronise across devices.

Backup & restore

Export a complete JSON backup containing patients, consultations, medicine index and doctor settings. Keep backups in a secure, access-controlled location.

Records are stored only in this browser profile on this device. They are not uploaded to DoctorJet. Export backups regularly and store them securely. Clearing website data, using a private window, or changing browsers can make records unavailable.
